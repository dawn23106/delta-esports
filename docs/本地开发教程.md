# 三角洲陪玩接单助手 — 本地开发启动教程

## 环境准备

确保以下软件已安装：

| 软件 | 版本 | 检查命令 |
|------|------|----------|
| JDK | 17+ | `java --version` |
| Maven | 3.9+ | `mvn --version` |
| MySQL | 8.0+ | `mysql --version` |
| Redis | 5.0+ (Windows) | `F:\Redis\redis-cli.exe ping` |
| Node.js | 18+ | `node --version` |
| npm | 9+ | `npm --version` |

## 第一步：启动 MySQL

MySQL 是 Windows 服务，开机自启，确认它正在运行：

```bash
mysql -uroot -p231062 -e "SELECT 1"
```

如果提示 `ERROR 2003: Can't connect`，说明 MySQL 没启动：
```bash
net start MySQL80
```

## 第二步：启动 Redis

```bash
# 打开一个新终端，直接运行
F:\Redis\redis-server.exe
```

看到 Ready to accept connections 就是成功了。不要把终端关掉。

验证：
```bash
F:\Redis\redis-cli.exe ping
# 返回 PONG
```

## 第三步：初始化数据库（仅首次）

```bash
mysql -uroot -p231062 < backend/src/main/resources/schema.sql
```

验证：
```bash
mysql -uroot -p231062 -e "SHOW TABLES FROM delta_helper;"
# 应看到 orders 和 users 两张表
```

## 第四步：启动后端

用 IDEA 打开 `backend/` 目录（以 Maven 项目导入），然后：

**方式 A — IDEA 直接运行：**
- 找到 `src/main/java/com/delta/DeltaApplication.java`
- 右键 → Run 'DeltaApplication'
- 控制台看到 `Started DeltaApplication` 就是成功了

**方式 B — 终端运行：**
```bash
cd backend
mvn spring-boot:run
```

验证：
```bash
curl http://localhost:8080/api/auth/login -X POST -H "Content-Type: application/json" -d "{\"phone\":\"13800000000\",\"password\":\"cs123456\"}"
# 返回 {"code":200,...} 即可
```

## 第五步：启动前端（两个终端）

**移动端（玩家 + 打手）：**
```bash
cd frontend-mobile
npm install        # 仅首次
npm run dev
# → http://localhost:5173
```

**管理后台（客服）：**
```bash
cd frontend-admin
npm install        # 仅首次
npm run dev
# → http://localhost:5174
```

## 第六步：打开浏览器

| 端 | 地址 | 谁用 |
|----|------|------|
| 移动端 | http://localhost:5173 | 玩家下单、打手接单 |
| 管理后台 | http://localhost:5174 | 客服管理订单/用户 |

## 预置账号

| 角色 | 手机号 | 密码 | 说明 |
|------|--------|------|------|
| 客服 | 13800000000 | cs123456 | 首次启动后端自动创建 |
| 玩家 | 自行注册 | - | 打开移动端注册 |
| 打手 | 先用玩家注册 | - | 客服在后台把玩家设为打手 |

## 体验完整流程

1. 打开 http://localhost:5173 → 注册一个玩家账号 → 下单
2. 注册第二个账号 → 打开 http://localhost:5174 → 客服登录 → 用户管理 → 把第二个用户设为 `booster`
3. 回到 http://localhost:5173 → 用打手账号登录 → 订单池看到刚下的单 → 接单 → 开始 → 完成

## 日常启动

以后每天开发只需：

```
1. MySQL 自动运行（不需要管）
2. 双击 F:\Redis\redis-server.exe
3. IDEA 运行 DeltaApplication
4. 终端1: cd frontend-mobile && npm run dev
5. 终端2: cd frontend-admin && npm run dev
```

## 常见问题

**Q: 后端启动报 "port 8080 already in use"**
```bash
netstat -ano | findstr :8080
taskkill -PID <PID号> -F
```

**Q: 前端报"网络错误"**
检查后端是否在 8080 端口运行，检查 MySQL 和 Redis 是否正常。

**Q: 登录报 500 错误**
查看 IDEA 控制台的错误日志，通常是 Redis 没启动或 MySQL 密码不对。

**Q: Redis 怎么关和开**
- 关闭：`F:\Redis\redis-cli.exe shutdown`
- 开启：`F:\Redis\redis-server.exe`
